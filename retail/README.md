# 散户综合指数（GitHub Pages）

手机入口：`https://mux4457986479-commits.github.io/a-stock-screener/retail/`。

沿用低价股看板的深色卡片和移动端布局；原低价股页面仅增加跳转链接。

- `index.html` 读取同目录 `data.json`；刷新按钮重读已发布快照，手动采集链接打开GitHub Actions。
- `scripts/engine.py` 是完整规则；`scripts/collect.py` 有限请求公开页面，不需要凭证。
- `scripts/update.py` 在临时目录采集，只导出匿名聚合及最多300条短摘录。原始响应、作者ID和本地路径不发布。
- 复用原 `.github/workflows/update-low-price.yml`，工作日北京时间09:00—15:30每30分钟自动采集；队列可能延迟。GitHub长期不活跃可能暂停计划任务。
- 页面当日社区与上个完整交易日交易行为分别显示；不跨日期伪造综合分。综合分缺失时保留上次有效日期。
- 每个平台至少10条、至少两平台且大盘合计50条；交易三因子齐全才发布综合分。缺失不补0、不放宽门槛。
- 接口失败保留旧快照并写入失败状态；社区覆盖不足是有效采集但不能计算，不当成接口故障。
- 日终历史与社区快照历史分开积累，不回填虚拟历史、不提供经过验证的反指买卖信号。
- 只读取公开网页；请保持合理频率。零Python第三方依赖，无API密钥和GitHub私人令牌进入网页。

原低价股脚本仅增加运行结束后的社区更新钩子，筛选算法和已有字段保持不变；社区快照作为根目录data.json的retail字段提交，原workflow无需修改。首次发布的retail/data.json只用于首次云端生成前的兜底。15:10之后才允许使用当日完整日线，盘中不拿半日成交量与全天比较。

为避免GITHUB_TOKEN提交不触发Pages重新构建而造成数据滞后，页面并行读取Pages同源快照与raw.githubusercontent.com的公开主分支快照，选择采集时间较新的有效数据。任一来源失败不覆盖已显示内容；日期仍按实际采集时间显示。
